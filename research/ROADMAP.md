# Experiment programme
Each stage is a proposal until owner approval. Change one variable at a time, use same immutable snapshot and settings, run offline tests and intercept payload before any paid run. Initial screening 50 decisions; ambiguous results inconclusive, not automatic acceptance.
| ID | Change | Acceptance evidence |
|---|---|---|
| W003-E00 | Mature baseline | Reproducible snapshot, verified initial state, complete telemetry |
| W003-E01 | Structured voluntary thought | Purpose, assessment, next step, evidence; subsequent action continuity without forced THINK |
| W003-E02 | Intention and progress | Verified attempts and outcomes support independent strategy revision; fewer repeated failures |
| W003-E03 | Reflective memory | Evidence-backed strategy/interest reflections recalled and applied |
| W003-E04 | Semantic precision | Separate enduring facts from temporary observations; test contradiction and revision |
| W003-E05 | Identity and autonomy | Independent interests and intentions without prescribed hobbies or neglected needs |
| W003-E06 | Simplify legacy guidance | Remove one behavioural mechanism at a time; preserve physical constraints |
| W003-E07 | Library | Voluntary reading, provenance distinct from personal experience, general memory reuse |
| W003-E08 | Long validation | Proposed 200 decisions plus restart persistence; accepted changes only |
W003-E00 completed the offline clock checks, encrypted snapshot restore, and the authorised 50-decision run. The [corrected results](experiments/W003-E00/corrected-results.md) document an inspection loop and the limits of what that run exercised. Further experiments require owner approval.

W003-E01 is provisionally accepted. [W003-E02 partial results](experiments/W003-E02/results.md) show one verified completion and a later recognition of a navigation loop. The 50-decision screening stopped early. E03 remains pending.
