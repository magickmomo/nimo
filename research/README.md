# Nimo research workspace
Shared handover between Chat (analysis/specification), Work (implementation/execution), and the owner (approval). Read STATUS.md first, then ROADMAP.md, OBJECTIVES.md and ARCHITECTURE.md. Existing historical experiments remain in ../experiments; do not duplicate raw logs.
Lifecycle: proposed → approved → implemented → offline verified → run → analysed → accepted/refined/rejected/inconclusive. Only owner-approved paid runs; no automatic reruns, production writes, main merges or deployments. Use separate experiment branches from the last accepted commit. Update STATUS on the shared research branch with links to experiment commits and artifacts. Record evidence, not claims of completion. Keep raw snapshots, secrets and private logs out of Git. 
Work handover: read status, execute only approved scope, report commit, tests, run ID, artifact, blockers and actual results. Chat handover: inspect source and artifacts, distinguish measured facts from interpretations, update analysis and propose next step. Owner approves acceptance.
